**Citation status: this facility's own, and deliberately not a published
method.** The protocol is 4.7 run after a heat step at four temperatures,
reporting residual binding. The repository is explicit that this is a
challenge rather than a melt, and that a T_m has nowhere to be read because
neither ATC version has optical detection. **Citing the DSF or nanoDSF
literature here would imply a measurement this protocol does not make**, so
nothing is cited.

## Method details

**Scale.** 384 per plate, ~3 h, four temperature points.

1. **Prepare the binding assay and split it four ways.** 4.7 is built once
   and split across four plates, one per temperature.
2. **Seal each plate** with thermal foil.
3. **Hold four temperatures at once.** Four blocks running independent
   programs, so the ladder costs **one pass rather than four**. On a single
   block the ladder would be four sequential runs.
4. **Peel** — up to 200 seals an hour.
5. **Read residual binding**, ~8 min per TR-FRET plate.

## Quantification and statistical analysis

**Residual binding after each step of the temperature ladder: four points,
not a T_m.** The four temperatures and any normalisation to an unheated
control are not specified in `_data/protocols.yml`, and a reference point at
ambient would be needed for "residual" to mean anything — it is not listed
among the four plates, which is worth settling before the first run.
**[inferred gap, not an inferred item]**

**Stated limitation, carried verbatim from the repository.** DSF is not
available. Neither ATC version has optical detection, so melt curves have
nowhere to be read. This gives real stability data, but not a T_m. The
repository's capability notes list nanoDSF as an unlock that would turn
thermostability into a product the way a commercial vendor sells it; it is
not quoted.

The workflow carries no gate.
